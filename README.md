# Image Recognition using CNN

This project is an AI-powered image recognition system built using Convolutional Neural Networks (CNNs).

## Technologies Used
- Python
- TensorFlow
- Keras
- HTML
- CSS
- JavaScript

## Features
- Image classification
- CNN model training
- Prediction system
- Web-based interface

## Files Included
- train_model.py → Model training
- app.py → Backend application
- model.h5 → Trained model
- index.html → Frontend page
